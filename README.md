# GEOMATCH

Dashboard de OKRs, KPIs, métricas de crecimiento e innovación desarrollado para el Bloque 2 de la Ficha S19.

## Contenido

- `index.html`: dashboard interactivo del Prompt 23.
- Valores reales editables y guardados en el navegador.
- Metas y proyecciones diferenciadas visualmente.
- Seguimiento de OKRs, economía por caso y embudo AARRR.

## Uso

Abra `index.html` en un navegador o consulte la versión publicada mediante GitHub Pages.

Los valores financieros mostrados como proyección o hipótesis provienen del modelo financiero de GEOMATCH y deben actualizarse con resultados reales de pilotos y ventas.
